# Dr Vučen laser centar

Moderni sajt za dermatovenerološku ambulantu u Banjoj Luci. Sadržaj je preuzet sa [drvucen.com](https://drvucen.com) (stari Joomla 1.5), uz novi raspored, mobilni prikaz i jasne kontakte.

## Pokretanje

```bash
npm install
npm run dev
```

Otvori [http://localhost:3000](http://localhost:3000).

## Šta je unutra

- Naslovna, usluge (3 oblasti + 18 tretmana), galerija, kontakt i mapa
- Tekstovi i fotografije sa postojećeg sajta
- Poziv na telefon kao glavni način zakazivanja

Zamjena live sajta: `npm run build`, pa statički ili Node hosting umjesto starog Joomla/PHP 5.6.
